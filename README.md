STROOP TEST — SELECTIVE ATTENTION (RANDOMIZED MIXED ORDER)

Run locally:
1. Extract this ZIP.
2. Open index.html in a modern browser.
3. Complete participant details and consent, then click Begin test.
4. Complete exactly 60 trials. Congruent and incongruent trials are interleaved in a shuffled order, with 30 trials per condition.
5. After trial 60, click View Results. Screenshot the result or use Print / Save as PDF.

Measurement:
- Each trial is timed from stimulus display to the participant's colour-button click.
- Time Taken is the sum of the 30 response times in each condition, rounded to the nearest millisecond.
- No. of Errors counts clicks that do not match the stimulus ink colour.
- Results are calculated from actual clicks and are not manipulated to support the hypothesis.
- Ink-colour counts are balanced within each condition; the combined trial order is shuffled.

Privacy and limitations:
- Educational, non-diagnostic activity, not a clinical assessment.
- Details and results stay in the current browser session; there is no server submission or analytics.
- Current version is intended for adults aged 18+.
- This ZIP does not create a public website URL. To share by link, publish index.html through GitHub Pages or Cloudflare Pages.
